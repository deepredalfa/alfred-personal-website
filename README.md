# Alfred Johnson — Personal Website

One-page personal branding site for Alfred Johnson, Data Engineer.

Built with plain HTML, CSS, and JavaScript — no frameworks, no build step.

## Structure

```
├── index.html   # All sections: Nav, Hero, About, Skills, Projects, Contact
├── style.css    # All styles (CSS variables, responsive layout)
├── script.js    # Mobile nav toggle + scroll-reveal animations
└── assets/      # Static assets (profile photo, favicon)
```

## Local development

Open `index.html` directly in a browser — no server required.

## Deployment

Deployed on [Vercel](https://vercel.com). Push to `main` to trigger automatic redeployment.
